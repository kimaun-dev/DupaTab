# DupaTab

DupaTab is a Chrome extension that finds duplicate tabs, groups matching URLs, and lets you manually choose which duplicate tabs to close.

## Features

- Scans all currently open Chrome tabs.
- Groups tabs that share the same URL.
- Ignores Chrome internal pages such as `chrome://`, `chrome-extension://`, and `about:`.
- Shows only groups with 2 or more duplicate tabs.
- Displays tab and duplicate counters.
- Lets you select duplicate tabs with checkboxes.
- Never closes tabs automatically.
- Requires manual confirmation before selected tabs are closed.

## Install manually

1. Download or clone this repository.
2. Open Chrome and go to `chrome://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the DupaTab project folder.

## Version

Current version: **1.0.0**

## Privacy

DupaTab works locally in your browser and does not require an API key or external account.
